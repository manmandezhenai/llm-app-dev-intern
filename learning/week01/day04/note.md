# Week01-Day04：函数基础

## 【核心知识点】

### 1. 函数基础定义

- 函数作用：封装可复用的代码块，减少重复代码，提升可维护性与可读性
- 定义语法：`def 函数名(参数列表): 函数体`，通过 `函数名(实参)` 完成调用
- 命名规范：统一蛇形命名法，通常以动词开头，见名知意，如 `calculate_score`
- 文档字符串：函数定义下方用三引号编写功能说明，可通过 `help(函数名)` 查看，工程化项目强制编写

### 2. 函数参数类型

| 参数类型    | 语法格式        | 核心说明                   | 示例                        |
|---------|-------------|------------------------|---------------------------|
| 位置参数    | 普通变量名       | 按顺序一一对应传参，调用时数量必须完全匹配  | `def add(a, b)`           |
| 默认参数    | `变量名 = 默认值` | 不传参时自动使用默认值，必须放在位置参数之后 | `def add(a, b=0)`         |
| 可变位置参数  | `*args`     | 接收任意多个位置参数，内部封装为元组     | `def calc_sum(*args)`     |
| 可变关键字参数 | `**kwargs`  | 接收任意多个关键字参数，内部封装为字典    | `def user_info(**kwargs)` |

- 参数顺序强制规则：位置参数 → 默认参数 → `*args` → `**kwargs`

### 3. 返回值机制

- 使用 `return` 关键字返回执行结果，函数执行到 return 语句会立刻终止并退出
- 无 return 语句时，函数默认返回 `None`
- 多返回值：return 后用逗号分隔多个值，自动封装为元组返回，支持多变量同步接收
- 工程建议：单一职责原则，一个函数只负责一个功能，返回值类型保持稳定

### 4. 变量作用域

- 局部变量：定义在函数内部，仅函数内可访问，函数执行结束后自动销毁
- 全局变量：定义在函数外部，整个文件范围内可访问
- 全局修改：函数内修改全局变量必须先用 `global 变量名` 显示声明
- 查找规则：函数内优先访问局部变量，局部不存在则向上查找全局变量

### 5. 匿名函数 lambda

- 语法：`lambda 参数: 表达式`，只能包含一行表达式，自动返回表达式结果
- 特点：无需定义函数名，临时一次性使用，代码简洁轻量
- 适用场景：简单逻辑处理，作为参数传递给 `sorted`、`filter` 等高阶函数
- 使用限制：只能包含单个表达式，不支持分支、循环等复杂逻辑

## 【今日易错点】

1. 函数定义语句末尾忘记加冒号，会直接触发语法错误
2. 默认参数必须放在位置参数之后，顺序颠倒会触发语法错误
3. 函数内修改全局变量前未加 `global` 声明，会被识别为局部变量导致报错
4. 可变参数 `*args` 接收的是元组，`**kwargs` 接收的是字典，类型混淆会导致操作错误
5. 函数没有 `return` 语句时默认返回 `None`，直接参与数值运算会触发类型错误
6. `lambda` 只能写单个表达式，多行逻辑无法实现，复杂场景应使用普通函数
7. 位置参数传参顺序错误，不会报错但会导致业务逻辑错误
8. 函数内部定义的局部变量，在函数外部无法访问，直接调用会触发 `NameError`
