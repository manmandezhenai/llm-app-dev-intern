# Week01-Day01：环境搭建与基础语法入门

## 【核心知识点】

### 1. 开发环境搭建

- Python 3.10+ 安装：从官网下载对应系统安装包，安装时勾选 **「Add Python 3.10 to PATH」**
- 验证安装：打开终端，输入 `python --version`，输出版本号即为安装成功
- PyCharm 配置：安装社区版（Community），新建项目时选择已安装的 Python 解释器（默认创建 `venv` 虚拟环境）
- 常用快捷键：`Ctrl + /`（单行注释 / 取消注释）、`Ctrl + Alt + L`（格式化代码）、`Shift + F10`（运行当前代码文件）

### 2. 变量与命名规范

- 变量定义：Python 为动态类型语言，无需声明类型，直接赋值即可创建，格式：`变量名 = 值`
- 命名规则：
    - 只能由字母、数字、下划线组成，不能以数字开头
    - 严格区分大小写（`name` 和 `Name` 是两个不同变量）
    - 禁止使用 Python 关键字（如 `if`、`for`、`class` 等）作为变量名
    - 推荐：使用蛇形命名法（小写字母 + 下划线），见名知意（如 `user_age`、`student_score`）

### 3. 基础数据类型

| 数据类型    | 说明                | 示例                  |
|---------|-------------------|---------------------|
| `int`   | 整数，支持正负整数与 0      | `100`、`-20`、`0`     |
| `float` | 浮点数，带小数的数值        | `3.14`、`-1.5`       |
| `str`   | 字符串，单 / 双引号包裹效果一致 | `"Hello"`、`'World'` |
| `bool`  | 布尔值，仅两个固定取值       | `True`、`False`      |

- 类型查看：使用 `type(变量名)` 可输出变量对应的数据类型
- 类型转换：`int()` 转整数、`float()` 转浮点数、`str()` 转字符串

### 4. 输入与输出

- 输出函数 `print()`：
    - 支持多值输出，逗号分隔（默认以空格分隔）
    - `end` 参数可修改结尾符（默认值为换行符 `\n`）
    - 推荐 f-string 格式化：`print(f"姓名：{name}，年龄：{age}")`
- 输入函数 `input()`：
    - 接收用户键盘输入，返回值**永远为字符串类型**
    - 基础语法：`变量名 = input("提示信息")`
    - 接收数值必须手动转换类型：`age = int(input("请输入年龄："))`

### 5. 代码注释规范

- 单行注释：`# 注释内容`
- 多行注释：三对双引号包裹，用于文件头部、函数、类的功能说明
- 注释原则：解释「为什么这么做」而非「代码做了什么」，关键逻辑必须注释

## 【今日易错点】

1. 安装 Python 时未勾选添加环境变量，导致终端无法识别 `python` 命令
2. 变量名以数字开头或使用 Python 关键字，直接触发语法报错
3. 字符串引号不配对，单引号开头用双引号结尾会触发语法错误
4. `input` 返回默认是字符串，直接参与数值运算会触发类型错误
5. Python 依靠缩进识别代码块，混合空格和 Tab 会触发缩进错误
6. 布尔值首字母必须大写，小写的 `true` / `false` 不是合法 Python 语法
