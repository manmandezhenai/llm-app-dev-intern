# Week01-Day03：流程控制与推导式

## 【核心知识点】

### 1. 条件分支语句

- 基础结构：`if 条件: 代码块`，条件成立则执行缩进内的代码块
- 多分支结构：`if-elif-else`，按顺序判断，第一个满足条件的分支执行后直接跳出
- 三元表达式：`变量名 = 结果1 if 条件 else 结果2`（适合简单二分支场景，一行完成赋值）
- 缩进规则：Python 依靠缩进识别代码块，同一代码块缩进必须一致（推荐 4 个空格）
- 条件判断：0、`None`、空字符串 / 列表 / 字典 / 集合都视为 `False`，其余视为 `True`

### 2. 循环语句

- for 循环：
    - 用于遍历可迭代对象（列表、元组、字典、字符串、range 等），语法：`for 变量 in 可迭代对象: 循环体`
    - `range(stop)`：生成 0 到 stop - 1 的整数序列
    - `range(start, stop)`：生成 start 到 stop - 1 的整数序列
    - `range(start, stop, step)`：按指定步长生成序列，步长可为负数实现倒序
    - `enumerate(序列)`：同时获取元素的索引与值
- while 循环：
    - 适合循环次数不确定的场景，语法：`while 条件: 循环体`
    - 条件持续成立则反复执行循环体，必须设置退出条件避免死循环

### 3. 循环控制关键字

| 关键字        | 作用                       | 适用场景                |
|------------|--------------------------|---------------------|
| `break`    | 立刻终止**整个循环**，跳出循环体执行后续代码 | 找到目标结果后提前结束循环       |
| `continue` | 跳过**当前单次循环**，直接进入下一次循环判断 | 跳过不符合条件的元素，不终止整体循环  |
| `pass`     | 空占位符，不执行任何逻辑，仅保证语法完整     | 代码块暂未实现逻辑，先占位避免语法报错 |

### 4. 推导式

- 列表推导式：
    - 语法：`[表达式 for 变量 in 可迭代对象 if 条件]`
    - 作用：快速生成新列表，代码简洁，执行效率高于普通 for 循环
    - 示例：`[x * 2 for x in range(10) if x % 2 == 0]`（生成 0-9 中偶数的两倍值列表）
- 字典推导式：
    - 语法：`{键表达式: 值表达式 for 变量 in 可迭代对象 if 条件}`
    - 示例：`{x: x ** 2 for x in range(5)}`（生成数字与平方的映射字典）

## 【今日易错点】

1. Python 依靠缩进识别代码块，同一代码块缩进不一致会触发 `IndentationError`
2. `if` / `for` / `while` 语句忘记加冒号，会直接触发语法错误
3. `range` 生成的序列是左闭右开区间，结束值不会被包含在结果中
4. `break` 会终止整个循环，`continue` 只跳过单次循环，混淆二者会导致业务逻辑错误
5. 三元表达式仅适合简单二分支场景，多层嵌套会严重降低代码可读性
6. 推导式支持条件过滤，但不建议写多层嵌套，避免代码难以维护
7. `while` 循环忘记更新条件变量，会导致程序进入死循环无法退出
8. `pass` 是空语法占位符，不会执行任何业务逻辑，不能替代实际功能代码
