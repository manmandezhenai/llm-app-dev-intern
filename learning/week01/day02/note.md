# Week01-Day02：核心数据结构（列表 / 元组 / 字典 / 集合）

## 【核心知识点】

### 1. 列表（List）

- 定义：有序可变的元素集合，支持存放不同数据类型元素，使用 `[]` 包裹
- 创建方式：直接赋值 `nums = [1, 2, 3]`、空列表 `[]`
- 索引与切片：
    - 正向索引从 0 开始，反向索引从 -1 开始
    - 切片格式 `列表[起始:结束:步长]`，遵循左闭右开规则（省略起始默认从头开始，省略结束默认到末尾）
- 常用方法：
    - 增加：`append(x)` 末尾追加单个元素、`extend(可迭代对象)` 批量追加、`insert(i, x)` 指定位置插入
    - 删除：`pop(i)` 删除指定位置元素并返回（默认删除最后一个）、`remove(x)` 删除第一个匹配元素、`clear()` 清空列表
    - 其他：`sort()` 原地排序、`reverse()` 原地反转、`index(x)` 查找元素第一个索引、`count(x)` 统计元素出现次数
- 适用场景：需要动态增删、有序存储的序列数据，如用户列表、任务队列、数据集合

### 2. 元组（Tuple）

- 定义：有序不可变的元素集合，使用 `()` 包裹，元素创建后无法修改、新增、删除
- 创建方式：直接赋值 `info = ("张三", 22)`、单个元素 `(10,)` 必须加逗号
- 支持操作：支持索引、切片、`index()`、`count()`，与列表只读操作一致
- 核心特性：不可变性，数据安全可靠，可作为字典的键使用
- 使用场景：固定不变的配置参数，函数多返回值、需要保证数据不被修改的场景

### 3. 字典（Dict）

- 定义：键值对映射集合，键唯一且必须是不可变类型，使用 `{key: value}` 格式
- 创建方式：`user = {"name": "张三", "age": 22}`、空字典 `{}`
- 常用操作：
    - 取值：`字典[key]`（键不存在报错）、`字典.get(key, 默认值)`（键不存在返回默认值）
    - 增改：`字典[key] = value`，键存在则修改值，不存在则新增键值对
    - 删除：`pop(key)` 删除指定键并返回对应值、`del 字典[key]`、`clear()` 清空字典
- 遍历方法：
    - 遍历键：`for k in 字典.keys()`
    - 遍历值：`for v in 字典.values()`
    - 遍历键值对：`for k, v in 字典.items()`（最常用）
- 适用场景：需要通过键快速查找值的映射场景，如用户信息、配置项、数据映射表

### 4. 集合（Set）

- 定义：无序不重复的元素集合，元素必须是不可变类型，使用 `{}` 包裹
- 创建方式：直接赋值 `nums = {1, 2, 3}`、空集合 `set()`（注意：`{}` 是空字典）
- 核心特性：自动去重（常用于列表 / 字符串去重）
- 集合运算：
    - 交集：`a & b` 或 `a.intersection(b)`，两个集合共有的元素
    - 并集：`a | b` 或 `a.union(b)` 两个集合所有元素去重合并
    - 差集：`a - b` 或 `a.difference(b)`，a 存在但 b 不存在的元素
- 常用方法：`add(x)` 添加元素、`remove(x)` 删除元素（不存在报错）、`discard(x)` 删除元素（不存在不报错）
- 适用场景：数据去重、集合关系判断、共同元素 / 差异元素查找

### 5. 四种数据结构选型对比

| 数据结构      | 有序性               | 可变性 | 核心特点          | 典型场景        |
|-----------|-------------------|-----|---------------|-------------|
| 列表`List`  | 有序                | 可变  | 灵活增删、索引访问     | 动态序列、队列、栈   |    
| 元组`Tuple` | 有序                | 不可变 | 只读安全、可做字典键    | 固定配置、函数多返回值 |    
| 字典`Dict`  | Python 3.7+ 按插入有序 | 可变  | 键值映射、O(1)快速查找 | 信息映射、配置字典   |    
| 集合`Set`   | 无序                | 可变  | 元素唯一、支持集合运算   | 数据去重、交集差集计算 |

## 【今日易错点】

1. 列表索引超出范围会触发 `IndexError`，使用索引前需确认列表长度
2. 元组只有一个元素时必须加逗号，否则会被识别为单个元素而非元组
3. 字典的键必须是不可变类型，使用列表作为键会触发 `TypeError`
4. 空集合必须用 `set()`创建，直接写 `{}` 创建的是空字典而非空集合
5. 集合是无序结构，无法通过下标索引访问元素，索引操作会报错
6. 列表 `sort()` 方法是原地修改，不会返回新列表，赋值接收会得到 `None`
7. 字典直接用 `[]` 取值时，键不存在会报错，优先使用 `get()` 方法避免报错
